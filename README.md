# BioGarden Paisagismo

Site institucional desenvolvido para um cliente real da área de paisagismo, com apresentação da empresa, produtos, materiais e paleta de cores.

**Ver online:** https://feernandoignacio.github.io/Biogarden-Paisagismo/

## Seções do site

- Sobre nós, missão e onde encontrar
- Produtos, com galeria em slide
- Materiais e paleta de cores
- Serviços e contato

## Destaques técnicos

- Layout responsivo, feito do zero em CSS
- Galeria em slide com setas, indicadores e arraste (touch), em JavaScript puro
- JavaScript separado em componentes: menu, slide, carregamento e medidas dos produtos
- Identidade visual do cliente aplicada em toda a página

## Tecnologias

- HTML5
- CSS3
- JavaScript (puro)

## Como rodar

Baixe ou clone o repositório e abra o `index.html` no navegador.

```bash
git clone https://github.com/feernandoignacio/Biogarden-Paisagismo.git
```
